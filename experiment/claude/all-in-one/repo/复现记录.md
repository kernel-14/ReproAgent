# 复现记录

## 修复点
- `all_in_one_sbi/model.py` 现在把 Simformer 的关键语义落到可执行路径里：Q/K/V 维度真的按 10 构造，训练 loss 使用 `lambda(t)=g(t)^2`，反向采样使用 Euler-Maruyama，并在每一步 clamp 已观测变量。
- `all_in_one_sbi/conditioning.py` 的 guided diffusion 改成了基于 denoised estimate `x0_tilde` 的 interval guidance，带 `log sigmoid(-s(t)c(x0_tilde))` 梯度和 forward-then-reverse self-recurrence。
- `all_in_one_sbi/attention_masks.py` 的 Webb-style 条件图更新现在会真的改变 `M_E`，而不是只停留在静态注释或完全密集化。
- `all_in_one_sbi/simulators.py` 补齐了 addendum 里的参考采样协议、HH 的 A2.2 rate/energy/summary 公式，以及 Tree/HMM 的参考采样步数语义。
- `all_in_one_sbi/training.py` 的训练 loop 现在显式使用 `training_batch_size=1000` 的 minibatch 路线，而不是把它只放在配置字典里。
- `main.py` 的 runtime smoke 入口已验证能写出顶层 artifact 和 `results/` 镜像 artifact。

## 低分原因
- 这轮低分的核心不是“缺文件”，而是“语义停在 metadata”。之前很多关键点只写在注册表、说明文字或静态 artifact 里，没真正进入 canonical route。
- 典型缺口有四类：1) 反向扩散没有严格按 paper 的 VESDE / Euler-Maruyama / clamp 路线执行；2) interval guidance 没有按 `x0_tilde` 和 `log sigmoid` 形式做 score modification；3) 条件图更新没有真正改变 `M_E`；4) HH / Tree / HMM / reference sampler 的论文级参数和步数虽然出现过，但没有被统一到可执行路径里。

## 剩余风险
- 默认 smoke 仍是 bounded route，不代表论文级 10^3 / 10^4 / 10^5 全量实验。
- 条件采样、guided diffusion 和 reference sampler 仍属于轻量可执行复现，不等于原论文的完整数值结果。
