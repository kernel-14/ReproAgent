# Stochastic Interpolants with Data-Dependent Couplings

This repository reproduces the paper **“Stochastic Interpolants with Data-Dependent Couplings”** with executable routes for:

- core stochastic interpolants with couplings,
- ImageNet in-painting,
- ImageNet super-resolution,
- FID evaluation and Table/Figure artifact writing,
- smoke-safe dry-run validation and canonical artifact closure.

The repository is organized so the default command exercises the same method surfaces as the full route, but with bounded inputs for fast validation.
