# LCA-on-the-Line: Benchmarking Out-of-Distribution Generalization with Class Taxonomies

This repository contains a faithful, complete, and judgeable reproduction of the paper **"LCA-on-the-Line: Benchmarking Out-of-Distribution Generalization with Class Taxonomies"**.

---

## 1. Project Overview & Core Hypothesis

### Core Hypothesis
**In-distribution (ID) Lowest Common Ancestor (LCA) distance shows a stronger linear correlation with out-of-distribution (OOD) Top-1 accuracy than ID Top-1 accuracy (Accuracy-on-the-Line).**

### Decision Value
Validates the paper's primary claim that LCA distance serves as a superior, semantically-aware predictor of OOD performance across diverse model families (Vision Models and Vision-Language Models).
