# Challenges in Training PINNs: A Loss Landscape Perspective

This repository provides a faithful reproduction of the experiments and analysis presented in "Challenges in Training PINNs: A Loss Landscape Perspective". The project investigates the ill-conditioning of Physics-Informed Neural Networks (PINNs) and evaluates the performance of various optimization strategies, including Adam, L-BFGS, and the proposed NysNewton-CG (NNCG) method.

## Setup and Installation

### Environment Requirements
- Python >= 3.8
- Core dependencies: `numpy`, `scipy`, `pyyaml`, `jsonschema`, `matplotlib`
- Training dependencies: `torch >= 1.11.0`
