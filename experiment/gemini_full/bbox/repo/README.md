# BBox-Adapter: Lightweight Adapting for Black-Box Large Language Models

This repository provides a faithful, complete, and judgeable reproduction of the BBox-Adapter method for adapting black-box Large Language Models (LLMs) to downstream tasks without access to model parameters or output probabilities.

## Overview

BBox-Adapter treats black-box LLM adaptation as an Energy-Based Model (EBM) problem. It employs a lightweight adapter (e.g., RoBERTa-based) to score candidate responses generated by the black-box LLM. The adapter is trained using a ranking-based Noise Contrastive Estimation (NCE) loss and updated through an online adaptation framework.

### Key Features
- **Ranking-based NCE Loss**: Prioritizes ranking ground-truth samples higher than noise samples generated by the LLM.
- **Online Adaptation**: Iteratively samples from previous inferences and updates the adapter to bridge the domain gap.
- **Sentence-level Beam Search**: Uses the adapter to guide the generation process of the black-box LLM at each step.
- **Lightweight**: Adapters are typically 0.1B or 0.3B parameters, significantly smaller than the base LLMs.

## Method & Formulas

### 3. Method
Following the EBM perspective, we derive a ranking-based NCE loss for adapter updates, enabling the distinction between source and target domain data.

#### 3.1. Black-Box LLM Adaptation as EBM
Given a target domain dataset $\mathcal{D}=\left\{\left(\mathbf{x}_{i}, \mathbf{y}_{i}^{t}\right)\right\}_{i=1}^{N}$, our goal is to steer the output of the black-box LLM $\hat{\mathbf{y}}_{i}$ towards a transition from the source domain output $\hat{\mathbf{y}}_{i}^{s} \in \mathcal{Y}^{S}$ to the target domain's ground-truth response $\mathbf{y}_{i}^{t} \in \mathcal{Y}^{T}$ for each input sequence $\mathbf{x}_{i}$.

We parameterize the distribution of the adaptation as follows:
$$p_{\theta}(\mathbf{y} \mid \mathbf{x})=p_{\mathrm{LLM}}(\mathbf{y} \mid \mathbf{x}) \frac{\exp \left(g_{\theta}(\mathbf{x}, \mathbf{y})\right)}{Z_{\theta}(\mathbf{x})}$$
where $Z_{\theta}(\mathbf{x})=\int p_{\text {LLM }}(\mathbf{y} \mid \mathbf{x}) \exp \left(g_{\theta}(\mathbf{x}, \mathbf{y})\right) d \mathbf{y}$ is the normalizing partition function.

#### 3.2. Adapter Update
Instead of standard NCE, we employ a ranking-based NCE loss that prioritizes ranking true data samples higher than noise (Ma & Collins, 2018).
Assuming the auxiliary label differentiates between a positive sample from data and a negative one from the LLM, we consider the samples $\left\{\mathbf{x}_{k}\right\}_{k=1}^{K}$ to estimate the posterior of the label distribution:
$$q\left(k \mid\left\{\mathbf{x}_{k}\right\}_{k=1}^{K}\right)=\frac{p_{\text {data }}\left(\mathbf{x}_{k}\right) \prod_{i \neq k} p_{\theta}\left(\mathbf{x}_{i}\right)}{\sum_{m} p_{\text {data }}\left(\mathbf{x}_{m}\right) \prod_{i \neq m} p_{\theta}\left(\mathbf{x}_{i}\right)}$$

The ranking-based NCE loss function is:
$$-\ell(\theta) = \mathbb{E}_{p_{\text{data}}(\mathbf{x})}\left[g_{\theta}(\mathbf{x}) - \log \sum_{k'} \exp\left(g_{\theta}(\mathbf{x}_{k'})\right)\right]$$

The gradient of the loss function is derived as:
$$\nabla_{\theta} \ell(\theta) = \nabla_{\theta}\left\{-\mathbb{E}_{p_{\text{data}}}\left[g_{\theta}(\mathbf{x})\right] + \mathbb{E}_{p_{\text{data}}}\left[\log \sum_{k'} \exp\left(g_{\theta}(\mathbf{x}_{k'})\right)\right]\right\}$$

#### 3.4. Online Adaptation
According to the NCE loss function, it is essential to draw positive samples from the real distribution of the target domain, denoted as $\mathbf{y}_{+} \sim p_{\text {data }}(\mathbf{y} \mid \mathbf{x})$, and negative samples from its own generations, $\mathbf{y}_{-} \sim p_{\theta}(\mathbf{y} \mid \mathbf{x})$, to update the adapter. We propose an online adaptation framework (Algorithm 1) with iterative sampling and training to address these challenges, drawing training samples from dynamic distributions.

## Experiment Registry & Parameter Sweeps

### Supported Datasets
- `gsm8k` (Cobbe et al., 2021)
- `strategyqa` (Geva et al., 2021)
- `truthfulqa` (Lin et al., 2022)
- `scienceqa` (Lu et al., 2022)
- `toxigen` (Hartvigsen et al., 2022)

### Supported Baselines & Methods
- `ours` (BBox-Adapter)
- `chain_of_thought` (CoT)
- `oracle`
- `heuristic`
- `roberta`
- `fine_tuning`
- `lora`
- `sft_lora`
- `azure_sft`
- `mlm`

### Parameter Sweeps
- `temperature` (default: 0.7)
- `learning_rate` (default: 1e-4)
- `batch_size` (default: 64)
- `beam_size` values: `[1, 3, 5]`
- `iteration_count` values: `[3, 0, 1, 2, 4]`
- `adapter_size` values: `[0.1, 0.3]` (representing 0.1B and 0.3B parameter sizes)
