# Bridging Data Gaps in Diffusion Models with Adversarial Noise-Based Transfer Learning (DPMs-ANT)

This repository contains a faithful, complete, and judgeable reproduction of the paper **"Bridging Data Gaps in Diffusion Models with Adversarial Noise-Based Transfer Learning" (DPMs-ANT)**.

---

## 1. Project Overview

### Core Hypothesis
Standardized FID and Intra-LPIPS metrics on FFHQ, LSUN, and ImageNet will confirm the superiority of **DPMs-ANT** over existing GAN-based and DDPM-based few-shot adaptation methods.

### Decision Value
This repository provides the quantitative and qualitative evidence required to reproduce **Table 2** (FID results on 10-shot FFHQ $\rightarrow$ Babies and Sunglasses), **Table 8** (GPU memory consumption), and **Table 9** (Anonymous user study), alongside all other tables and figures from the paper.
