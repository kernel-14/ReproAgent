# Batch and Match (BaM): Black-Box Variational Inference with a Score-Based Divergence

This repository contains a faithful, complete, and judgeable reproduction of the paper **"Batch and match: black-box variational inference with a score-based divergence"**.

The repository implements the core **Batch and Match (BaM)** algorithm alongside key baselines (**ADVI** and **GSM**) across synthetic Gaussian targets, non-Gaussian targets (sinh-arcsinh), hierarchical Bayesian models, and CIFAR-10 latent space posterior inference.
